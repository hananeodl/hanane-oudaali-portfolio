# Hanane Oudaali — Developer Portfolio

A clean, engineering-focused, responsive portfolio built with plain HTML/CSS/JavaScript.

## Included

- Responsive developer portfolio
- Dark/light mode with localStorage
- Mobile navigation
- Scroll progress indicator
- Project category filters
- Interactive project detail modal
- Copy-email interaction
- CV link
- Sections for experience, projects, skills, education, certifications, soft skills, languages and contact
- Folders ready for project screenshots and certificate images

## Run locally

You can simply open `index.html` in a browser.

For a local server (recommended):

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Add your images

Put project outcome screenshots in:

`assets/projects/`

Put certificate images in:

`assets/certificates/`

The current project cards use clean visual placeholders so the portfolio already looks complete. Once you have your screenshots, the visual panels can be replaced with them.

## Deploy

Recommended: Vercel or GitHub Pages.

Because this is a static site, no build step is required.

## QR code

After deployment, use the included `qr.html`:

1. Open `qr.html`.
2. Paste the final portfolio URL.
3. Generate the QR code.
4. Save/print it on your CV.

Do not generate the final CV QR code until the portfolio URL is stable.

## Important

The content is based on the information supplied for this portfolio and the uploaded CV. Before publishing, verify contact details, dates, certificate status, and project descriptions.
